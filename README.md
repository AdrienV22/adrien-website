# Portfolio — Application Astro

Site du portfolio **Adrien Valo** (Expert en Ingénierie Logicielle, RNCP).

- **Stack** : Astro 3, TypeScript, CSS (design system + thème clair/sombre).
- **Contenu** : Markdown dans `src/content/` (collections `work`, `parcours`, `skills`).
- **Build** : `npm run build` → sortie statique dans `dist/`.

Pour la **documentation technique complète** (architecture, collections, pages, design system, navigation circulaire, déploiement), voir le **[README à la racine du dépôt](../README.md)**.

## Commandes

```bash
npm run dev      # Développement
npm run build    # Build production
npm run preview  # Prévisualisation du build
```
